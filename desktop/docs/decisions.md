| 2026-11-01 | A job whose part or fixture geometry the gate needs (outline, margin, datum, nest origin, keep-outs) is `needs_measurement` is refused (hard, H7/H8). Unmeasured fixture tolerance only flags (S4). | coding agent (owner to confirm) |
| 2026-11-01 | Machine parameter ranges (H5) are the observed envelope, so the gate refuses untested values instead of assuming machine limits: VS 10..40, VZ 5..40 (CONFIRMED), PZ 0..100, DZ 100..500 (STRONG), VD 15 only (CONFIRMED, one value). Widening needs a logged observation. | coding agent (owner to confirm) |
| 2026-11-01 | Opcode allow-list (H4) for the M20 IQ: wire-confirmed `DR MC VS VZ PZ DZ VD ZA PD PU JF`; `LB NR` reserved, not emitted in M1/M2. | coding agent (owner to confirm) |
| 2026-11-01 | Bench overrides: `--set k=v` on a draft recipe only, for vs, vz, vd, pz, dz, stepover_mm, hatch_angle_deg, contour_pass, min_char_height_mm, tip_width_mm. | 2026-11-01 | The driver's fixed home job, queued by `send_gts(home_first=True)`, is gated by `gate.home.check_home_job` before every send, so no unchecked bytes reach USB. | coding agent (owner to confirm) |

| 2026-11-01 | Bench build worker: one `ThreadPoolExecutor(max_workers=1)` thread, 150 ms debounce, generation counter. Unreadable override or keep-out text drops the current report. | coding agent (owner to confirm) |
| 2026-11-01 | Bench send: the connection opens on the first Send (no separate Connect button).
