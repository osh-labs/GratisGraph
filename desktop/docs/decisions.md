| 2026-11-01 | Machine parameter ranges (H5) are the observed envelope, so the gate refuses untested values instead of assuming machine limits: VS 10..40, VZ 5..40 (CONFIRMED), PZ 0..100, DZ 100..500 (STRONG), VD 15 only (CONFIRMED, one value). Widening needs a logged observation. | coding agent (owner to confirm) |

| 2026-11-01 | The driver's fixed home job, queued by `send_gts(home_first=True)`, is gated by `gate.home.check_home_job` before every send, so no unchecked bytes reach USB. | coding agent (owner to confirm) |

| 2026-11-01 | Gate geometry (H7, H8) uses IEEE double arithmetic in device units with only + - * / (no sqrt, no libm), comparing squared distances; a tolerance EPS = 1e-6 units (1e-8 mm) absorbs mm-to-unit representation error, so a point exactly on a boundary in mm is judged on it and one unit (0.01 mm) past it is always refused. | coding agent (owner to confirm) |
| 2026-11-01 | Polygons in the gate are closed sets. H7: the allowed region is closed (a pen-down point exactly at the margin passes, also with a zero margin); a segment is split at every boundary crossing so concave outlines and holes are exact. H8: a keep-out is closed, so a position or move that touches its edge is refused. | coding agent (owner to confirm) |
| 2026-11-01 | H5 also refuses any setup opcode (DR MC VS VZ PZ DZ VD) after the setup block except the single `MC 0` before the return home, an unmeasured recipe setup value, and a setup opcode whose machine range is missing or unknown. H1, H2 and H6 refuse when the work field, the model code or the tool's `needs_spindle` is unknown. H9 also refuses a `ZA` not immediately followed by `PD`, and `PD` with a non-zero argument. | coding agent (owner to confirm) |
| 2026-11-01 | A hard rule reports at most 20 findings, then one finding counting the rest. S2 gives one flag for all operations below the minimum (S3 stays one per region); S5 flags a job whose run time cannot be estimated. | coding agent (owner to confirm) |
| 2026-11-01 | `gate.home.check_home_job(data, machine, *, target_model_code=None)` returns an ordinary GateReport: rule id `HOME`, entries = the machine only, selection = `Selection(machine=<id>)`, no residual lines, no estimate. `ggdesk check` exits 1 (error) when the job cannot be built, since without the intent there is nothing to judge H10 against. | coding agent (owner to confirm) |
